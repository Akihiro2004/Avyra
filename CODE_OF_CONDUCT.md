# Code of conduct

Avyra should be a place where people can learn, ask questions, and disagree without making the project unpleasant for everyone else.

Please be respectful, patient, and specific. Critique the code or idea, not the person. Harassment, threats, discrimination, sexual attention, doxxing, and deliberate disruption are not accepted in project spaces.

Maintainers may edit or remove comments, issues, pull requests, or contributions that break these rules. Repeated or serious behavior can lead to a temporary or permanent ban from the project.

If something happens that should not be handled publicly, use the private reporting option in [`SECURITY.md`](SECURITY.md). Reports will be reviewed as privately and fairly as possible.
