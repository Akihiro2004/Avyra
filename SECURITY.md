# Security policy

## Reporting a problem

Please do not open a public issue for a vulnerability, leaked credential, unsafe authentication flow, or a bug that exposes private listening or account data.

Use the repository's private vulnerability reporting page:

<https://github.com/Akihiro2004/Avyra/security/advisories/new>

Include the affected version, Android version, steps to reproduce, expected impact, and a minimal proof when it is safe to share. Remove real cookies, account tokens, signing keys, and personal data.

The maintainer will confirm the report when possible, investigate it, and coordinate a fix before public details are posted. There is currently no paid bug bounty.

## Supported versions

Security fixes are made for the latest published release and the current `main` branch. Older sideloaded builds may not receive fixes.

## Account safety

Avyra talks to third-party services and includes optional unofficial integrations. Never send a maintainer your Google cookie, Discord token, Last.fm secret, signing key, or module credentials. A legitimate bug report should not require the real value.
