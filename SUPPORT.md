# Getting help

Use [GitHub Discussions](https://github.com/Akihiro2004/Avyra/discussions) for setup questions and ideas when Discussions is available. Use the issue tracker for reproducible bugs and feature requests.

Before opening a bug, please check the latest release and search existing issues. Include:

- Avyra version
- Android version and device model
- The screen or feature involved
- Clear steps to reproduce it
- What you expected and what happened
- A short log with private values removed

Third-party music, lyric, and account services can change outside this project. A report is still useful, but a service outage or account restriction may not be fixable in Avyra.

For a security or privacy problem, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.
