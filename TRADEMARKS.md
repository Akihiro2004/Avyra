# Avyra name and logo

The open-source license covers the code under its stated terms. It does not give permission to pretend that a modified build is an official Avyra release or that the Avyra maintainer approved it.

You can describe a fork honestly, including saying that it is based on Avyra. If you publish a modified build, use a name and app icon that clearly separate it from the official project unless the maintainer has given permission to keep the Avyra branding.

This policy does not limit uses that are allowed by applicable trademark law, such as truthful references, commentary, or compatibility statements.
